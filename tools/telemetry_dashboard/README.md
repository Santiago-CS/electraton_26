# BE KEY Telemetry Suite — ITESO Racing Team

Herramienta de análisis post-carrera y telemetría vehicular desarrollada para el monoplaza eléctrico del equipo BE KEY ITESO Racing Team.

## Funcionalidades
- Sincronización multicanal de dinámicas de chasis y tren motriz eléctrico.
- Trazado satelital GPS con mapa de calor de velocidad.
- Diagrama G-G (Círculo de tracción / Aceleración longitudinal vs lateral).
- Lectura de variables CAN (temperaturas, voltajes de pack, corriente, RPM).
- Interfaz gráfica acelerada con PyQt6 y PyQtGraph.
